# Food cost KARIMOFF — исходные цены и отходы

Дата фиксации: 1 сентября 2026 года.

## Как считается себестоимость

Цена закупочной единицы рассчитывается как `цена упаковки / размер упаковки`. Для рецепта указано чистое количество продукта. Закупочное количество с учётом отходов считается по формуле:

`брутто = нетто / (1 - отходы / 100)`

Итоговый food cost товара показывается только тогда, когда цена заполнена у каждого ингредиента его техкарты. Нулевая цена больше не считается достоверной себестоимостью.

## Основание норм отходов

- Для белокочанной капусты используется 20%: кочерыжка и наружные листья.
- Для свежего помидора используется 5%: плодоножка и небольшая зачистка.
- Для свежего неочищенного огурца используется 5%: кончики и зачистка.
- Для красного лука используется фактическая оценка кухни 5%. Справочная норма полной очистки репчатого лука выше — 16%; поэтому этот коэффициент нужно проверить контрольным взвешиванием одной закупочной партии.
- Для маринованных огурцов ГОСТ задаёт минимум 50–55% овощей в массе нетто консервов. Пока этикетка конкретной банки не получена, применён консервативный минимум 50% и ещё 5% обрезки от массы самих огурцов: полезный выход 47,5%, совокупные потери 52,5%.
- Для листового салата использована временная розничная база 100 ₽ за 100 г и 20% отхода. Это округлённый рабочий ориентир между дешёвым салатом в горшочке и фасованным листовым салатом; после первой закупочной накладной его нужно заменить фактической ценой.

## Что ещё нужно запросить

У всех активных блюд и соусов есть полная расчётная себестоимость. Для точного, а не временного расчёта нужны закупочные цены листового салата и четырёх фирменных соусов: барбекю, чесночного, Цезарь и Тейсти.

Напитки «Добрый» выведены из активного меню. Их исторические карточки сохранены, чтобы не повреждать старые заказы и аналитику; закупочные цены для них сейчас не требуются.

Для точной цены маринованных огурцов нужна фотография этикетки с полями «масса нетто» и «масса основного продукта». После этого оценку 52,5% следует заменить фактическим выходом.

## Контроль на кухне

Норматив — стартовое значение. Для капусты, помидоров, свежего огурца и красного лука рекомендуется один раз взвесить целую закупочную партию до обработки и пригодный продукт после обработки. Фактический процент затем вносится в `Админка → Ингредиенты → Цены и упаковки`; все связанные блюда пересчитаются автоматически.
