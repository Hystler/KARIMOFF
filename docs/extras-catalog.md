# Допы к блюдам

Раздел `/admin/ingredients/extras` доступен владельцу и администратору.
Установка создаёт группу «Допы KARIMOFF» в активных пищевых категориях,
используя существующую модель модификаторов. Напитки исключены.
Повторная установка не создаёт дубли и не перезаписывает изменённые цены.
Кнопка сохранения цены обновляет соответствующий доп во всех блюдах.
Закупочная стоимость редактируется отдельно в ингредиентах.

20 вариантов: фри, жареный лук, сырная палочка, бекон, халапеньо,
чеддер, семь соусов, говяжья котлета, три вида мяса и три колбаски.
Обычные добавки стоят 40 рублей. Котлета: 200; говядина: 300;
свинина: 140; курица: 110; колбаски: 100/100/160 рублей.
Цены предварительные, food cost 20% для всех допов не гарантируется.

Халапеньо создаётся с неизвестной закупочной стоимостью (0 в текущей
модели, в интерфейсе «Данные уточняются»). Существующие цены не меняются.
Для бекона, чеддера и колбасок сохранены закупочные штуки; соответствие
одной штуки заявленной массе предварительное и помечено в интерфейсе.
Рецептуры, заказы, остатки и фискальные документы установка не изменяет.
Каталог общий для production и тестового стенда: установка влияет на оба.
Миграция схемы не нужна. Для отмены доступности архивировать группы/опции,
не удаляя модификаторы из истории заказов.

## Яндекс Еда

09.09.2026 через существующий кабинет направлен запрос поддержки на
read-only доступ к истории заказов, без изменения текущего приёма заказов.
Обращение принято в работу. API-credentials пока не получены; интеграция
не объявляется подключённой. Не использовать браузерные сессии вместо API-ключей.

Официальный метод истории:
https://yandex.ru/dev/eda-vendor/doc/ru/ref/Vendor-Management-Integration-API/partner.orders.history.post

До получения доступа не переключать ресторан и не импортировать продажи
по догадкам. Новые записи должны иметь отдельный канал и внешний ID для дедупликации.
